# UPDATE SCHEMATIC ESP32 DISPENSER

- [ ] pindah relay yang "io2" ke pin tombol tiket "i39". Soalnya "io2" itu strapping pin, jadi ga bisa masuk ke upload mode kalau di pasang relay, relaynya pulldown
- [ ] tombol tiket "i39" pindah ke "io0" jadi fungsinya bisa untuk tombol tiket dan upload mode
- [ ] pindah led server "io14" ke pin "io2"
- [ ] sekarang kita punya pin kosong di "io2"
