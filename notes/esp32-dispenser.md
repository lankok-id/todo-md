# UPDATE SCHEMATIC ESP32 DISPENSER

- [ ] pindah relay yang "io2" ke pin LED server "i014". Soalnya "io2" itu strapping pin, jadi ga bisa masuk ke upload mode kalau di pasang relay, relaynya pulldown
- [ ] pindah "io14" ke pin "io2"
- [ ] pindah tombol reset "i36" ke pin "io0", jadi fungsinya bisa untuk tombol reset dan upload mode
